# Puro Cielo для Windows

Оболочка восстановлена из официального установщика 1.7.0. Теперь Windows собирает тот же плеер из `web/`, что сайт и Android. Профиль хранится в прежнем `%APPDATA%/puro-cielo`; удаление приложения не удаляет медиатеку.

На Windows с Node.js 24:

```sh
npm install --prefix web
npm ci --prefix windows
npm run prepare-player --prefix windows
npm test --prefix windows
npm run build --prefix windows
npm run smoke --prefix windows
```

Установщик: `windows/dist/PuroCielo-Setup.exe`. Workflow **Release Windows** собирает его и проверяет запуск упакованного приложения, импорт WAV, воспроизведение, паузу и отдельное окно мини-плеера. Затем публикует релиз `windows-<версия>`. Версия берётся из `web/package.json`.

В приложениях вход для синхронизации доступен по почте. Google OAuth используйте на сайте; встроенные окна Electron/WebView не поддерживают этот сценарий входа. Для аккаунта Google можно задать пароль через «Забыли пароль?» на сайте.

## Синхронизация текста на сайте через приложение (1.15.0)

1. Запустите Windows-приложение на том же компьютере, где открыт официальный сайт.
2. На сайте откройте настройки → «Синхронизация через Windows» → «Подключить Windows».
3. Разрешите браузеру доступ к локальной сети, если он спросит, и включите «Автосинхронизация Genius».

Приложение должно оставаться открытым. После его перезапуска или обновления страницы подключитесь снова. Кнопка «Проверить и уточнить» использует тот же локальный обработчик. Отмена и отключение прекращают задачу сайта. Песни длиннее 15 минут пропускаются. Demucs, Whisper и CTC работают на CPU; первая загрузка моделей требует интернета и нескольких ГБ места. Модели и вокал кэшируются в существующем профиле. Аудио передаётся только на этот компьютер, хостинг не требуется.

Транспорт: HTTP на `127.0.0.1:43127`, только Origin `https://purocielo.github.io`, проверка Host, случайный токен на запуск приложения. Метаданные перед WAV: uint32 little-endian длина UTF-8 JSON, JSON, WAV. Задачи имеют отдельные идентификаторы отмены. Сайт не получает доступ к путям или произвольным файлам компьютера. Локальная копия сайта и другие домены не подключаются. Если порт занят, плеер продолжает работать, но подключение сайта недоступно.
