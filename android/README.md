# Puro Cielo — Android

Оболочка (WebView) вокруг плеера: вся медиатека грузится из ОДНОЙ папки (как в Poweramp), музыка играет в фоне.

## Как получить APK
APK собирается сам при каждом пуше (Actions → **Build**) и выкладывается в Releases:
https://github.com/PuroCielo/PuroCielo/releases/latest/download/PuroCielo.apk

Либо откройте папку в Android Studio и нажмите Build → Build APK(s). Версия берётся из `web/package.json`.

## Использование
Первый запуск → «Выбрать папку с музыкой» → выберите папку. Новые файлы подхватываются при каждом запуске, кнопка «Обновить» — в Настройках.

Плеер лежит в `app/src/main/assets/www` — это сборка из `web/` (`node web/build.js`), руками его не правьте.

## Подпись и обновления

У опубликованных APK 1.11.1 и 1.11.2 разные сертификаты: прежняя сборка создавала новый отладочный ключ на каждом запуске GitHub Actions. Android не разрешает обновлять приложение APK с другим ключом. До переустановки синхронизируйте лайки, плейлисты и настройки с аккаунтом; музыкальные файлы остаются в выбранной папке. Локальная история прослушиваний в синхронизацию не входит.

Для постоянной подписи добавьте в **Settings → Secrets and variables → Actions**:

- `PURO_SIGNING_KEYSTORE_BASE64` — keystore в Base64;
- `PURO_SIGNING_STORE_PASSWORD` — пароль keystore;
- `PURO_SIGNING_KEY_ALIAS` — имя ключа (по умолчанию `purocielo`);
- `PURO_SIGNING_KEY_PASSWORD` — пароль ключа, если отличается от пароля keystore.

Используйте исходный ключ, если нужно обновление поверх уже установленной версии. Не публикуйте keystore и пароли в репозитории. Без этих Secrets сборка сохраняет прежний режим debug-подписи и выдаёт предупреждение; постоянная подпись требует настройки владельцем репозитория.
